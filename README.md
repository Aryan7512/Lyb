# The evidence behind Option E

**Live site: https://lyb-opal.vercel.app/**

Team KSTS, NMIMS MPSTME, Mumbai: Aryan Tiwari, Shaman Shetty, Palash Chowdhury.

This is the optional research appendix to our Round 1 submission for the LYB Mumbai Hackathon 2026 ("Factory of 2036"). It shows the sources behind our choice of Option E, AI-based energy optimisation, for the fictional Plant X. For each source it gives what the source shows and the design choice it shaped.

The site is a single static `index.html` with no build step.
